## 1. What was built

One competence term in `managerScores`, gated OFF by default: from round
`SHARP_R0` on, a manager stops feeding categories his roster has already
conceded (z-sum ≤ `SHARP_DEAD`) and pays up for the ones still in reach,
weighting the weakest live category hardest (`SHARP_W`). `adp_w`,
`val_w`, `noise`, `bias`, `loyal` untouched — personality preserved,
only competence moved. Plus an opt-in SHARP ROOM toggle (setup UI, state
flag, log line, export field), all verified working by a 10-assertion
fake-DOM test.

**Method.** Full mock drafts generated by the **deck's own AI** in a fake
DOM (new harness: `room_driver.js` + the deck's engine/data/judgment
blocks), CRN-paired — for each (seed, slot) the default and sharp rooms
share the seed, the cast shuffle, and the owner's policy, so the ONLY
difference is bot competence. Rosters graded by the v2 instrument, 18,000
seasons each. Eight rooms across seats 1/3/4/6/8/10/12, punted and
unpunted, two owner policies (shipped-card follow; mock-40 picks).

## 3. Why it failed — structural, not a tuning miss (EVIDENCE)

Before concluding, `SHARP_W` and `SHARP_R0` were swept on **held-out dev
seeds** (9001–9004, disjoint from the eight evaluation rooms; roster
diagnostics need no simulation, so the evaluation set stayed clean):

| Setting | dead-kept | | Setting | dead-kept |
|---|---|---|---|---|
| W=12 | 1.48 | | R0=3, W=20 | 1.43 |
| W=20 | 1.34 | | R0=4, W=45 | 1.59 |
| W=30 | 1.55 | | R0=5, W=20 | 1.48 |
| W=45 | 1.45 | | R0=6, W=30 | 1.48 |
| W=65 | 1.50 | | R0=8, W=45 | 1.45 |
| W=90 | 1.34 | | *default* | *1.66* |

**Raising the weight 7.5× moves the metric by 0.14, and no round
threshold helps.** The term is not underpowered — it is aimed wrong.

**The mechanism:** "dead kept categories" is measured against each team's
own best 3-cat frame, so getting to ≤0.8 requires *concentrating* z-mass
into six categories. My term only ever ADDS to whatever is currently
weak — a spreading rule. Concentration requires the opposite: deliberate
**concession**. The owner's own five-draft run proves it (declare three
categories dead in R1–R7, pour everything into the other six); no
amount of late-round "help the weak cat" can reproduce that, because by
round 8 the eight-player core has already fixed the category profile.

**Coherence requires concession, and a bot that never concedes cannot
be made coherent by a bonus term.**

## 4. Registered follow-up: E25b (frame-declaring bots)

The diagnosis names the design that would work: give each manager a
**declared frame** — after R3–R4, when its roster identity is legible,
the bot picks the 3-cat punt its roster best supports and drafts to it
for the rest of the draft, conceding those cats outright.

Registered with the **same bar text as E25** (dead-kept ≤ 0.8, bot ECW
≥ +0.05, owner champ ≤ −3pp, realism guard byte-identical). Known
counterweight to measure honestly, not assume: G1a measured punt-
*declaring* policies at −5 to −11pp for the OWNER's card. Whether that
transfers to bots is an open empirical question — if declared frames make
the bots weaker rather than stronger, that is the answer and it gets
written up.
